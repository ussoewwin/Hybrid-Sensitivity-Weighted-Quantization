# SD1.5 HSWQ V1.1 ComfyUI 节点全流程集成与工作流自动化规范 (v2.4.8)

## 概述

v2.4.8 正式在 ComfyUI 内提供完整的 **SD1.5 HSWQ V1.1 轨迹影响度反向混合量化（Trajectory-Impact Hybrid Quantization）** 原生节点支持。

继 v2.4.7 CLI 轨迹影响度管线发布后，本版本将整个三阶段管线——从单层降噪轨迹偏离度实测、Top-K FP16 保护与 INT8 混合打包，到 25 随机种子确定性潜在轨迹验收门禁——全部封装为 ComfyUI 官方节点，彻底免除手动终端操作。

---

## 1. ComfyUI 节点体系与架构规范

SD1.5 工作流量化管线由三个专用节点构成，具备高精度重现、零成本复用及全程自动化特性：

### 1.1. 第一阶段：单层轨迹敏感度实测 (`HSWQ Diag Impact (ConvRot INT8)`)
- **分类:** `HSWQ/Quantize`
- **模型架构选择:** `model_type = "SD1.5"`
- **测试机制:** 针对 UNet 中所有 282 个符合 ConvRot 条件的权重层逐一执行降噪轨迹偏离度测量（25 步，固定 Prompt，CFG 7.0，Seed 42）。
- **扰动坐标系要求:** 必须在**原始坐标系**下将当前单层替换为 ConvRot INT8 重建权重（`(q * s) @ H`），其余所有层保持纯净 FP16。此机制直接捕捉误差在深度网络中的非线性传递与放大，避免在旋转坐标系下测量引入旋转矩阵自身偏差。
- **输出:** 将全模型轨迹敏感度诊断结果写入 `impact/impact_sd15_traj_<model_stem>.json`。

### 1.2. 诊断文件零成本快速复用 (`HSWQ Load Diag Impact Json`)
- **分类:** `HSWQ/Quantize`
- **功能机制:** 自动枚举 `<repo>/impact/` 目录下存储的 `impact_sd15_traj_*.json` 文件并提供下拉选择。
- **工作流联动:** 与 `HSWQ Diag Impact` 共同接入 `ImpactSwitch` (`Switch (Any)`)：
  - `select = 1`: 触发全新的第一阶段实测。
  - `select = 2`: 瞬间复用已有诊断结果。
- 允许开发者在无需重复耗费约 12 分钟实测时间的情况下，任意调整保护层数量 $K$（如 $K=80$ 与 $K=82$ 对比）并立即生成量化包。

### 1.3. 第二与第三阶段：混合打包与验收门禁 (`HSWQ Quantize ConvRot INT8`)
- **分类:** `HSWQ/Quantize`
- **模型架构选择:** `model_type = "SD1.5"`
- **输入端子:** 接收来自加载器的 `model`、`clip`、`vae` 以及切换器传递的 `impact_json`。
- **第二阶段混合打包:**
  - **Top-$K$ FP16 保护机制:** 根据轨迹影响度排序，将敏感度最高的 $K$ 个关键层（推荐 $K=80 \sim 82$）完全保留为原始 FP16，权重与基底 100% 逐字节一致。
  - **ConvRot INT8 全量量化:** 其余 2D `Linear` 与 4D `Conv2d` 层全部转化为 ConvRot INT8（Hadamard 分组大小 256，FP32 `weight_scale`，注入 `.comfy_quant` 元数据）。
  - **系统误差偏置修正:** 可选启用 INT8 偏置修正 (`E[(W_q - W) x] ~ (W_q - W) @ E[x]`)，利用校准集均值抵消量化带来的系统性漂移。
  - **CLIP 文本编码器透传:** 保持 `cond_stage_model.*` 100% 原始 FP16 存储，严禁产生 `.comfy_quant` 或 `.weight_scale` 等量化伪影。
  - **嵌入式 VAE 自动剥离:** 彻底剔除 `first_stage_model.*` 权重，大幅节省存储与显存（量化后约 1.16 GB，原始包约 2.03 GB）。
- **第三阶段确定性轨迹门禁:**
  - 量化完成后立即启动 25 随机种子确定性潜在空间轨迹对比（512x512，25 步，CFG 7.0）。
  - 生产验收门禁：平均余弦相似度 $\ge 0.95$ 且 **0/25 分歧破坏**。
  - 将实时进度与最终评测得分无缝输出至 `ShowText` 画布节点。

### 核心实验结论：
1. **零分歧破坏物理保障:** 在 7 款模型的全部 175 次种子测试中，HSWQ 与原生 INT8 均未出现单次轨迹跳变分歧（0/175，0.0%）。
2. **潜在精度显著提升:** HSWQ 全系平均终态余弦相似度达到 **0.96914**（原生 INT8 为 **0.95266**，提升 +0.01648），在 7 款模型中 6 款取得绝对胜出。
3. **误差大幅压缩:** 全系潜在均方误差（MSE）由原生 INT8 的 **1.6656** 降至 **1.0521**，整体误差抑制达 37%。
4. **杜绝严重漂移崩溃:** 在复杂的多模型合并模型（`0.7_0.7hassaku+0.3dreamshaper_8_0.3anylora`）中，原生 INT8 在 seed 42 下余弦相似度暴跌至 0.63851（最大单步落差 0.0469，濒临分歧临界）；而 HSWQ 稳定保持在 0.88097，有效锁定画面语义与构图。

# Sage-Attention for Windows (Unofficial Build)

This repository contains unofficial Windows wheels for **Sage-Attention 2.2＆3-1.0**, compiled with **CUDA 13.2**.

## Supported Environments

* **OS**: Windows (x64)
* **CUDA**: 13.2
* **Python**:
    * Python 3.12 (`cp312`)
    * Python 3.13 (`cp313`)
    * Python 3.14 (`cp314`)

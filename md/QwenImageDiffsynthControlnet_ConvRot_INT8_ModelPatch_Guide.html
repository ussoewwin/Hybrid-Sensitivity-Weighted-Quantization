1 · What the score is

The score is not a static weight statistic (kurtosis, absmax, outlier ratio). It is the observed change of the model's own output when a layer is perturbed — a behavioural measurement, taken in the frame the runtime uses.

For block i of the 60 control blocks:

cos_i = <r_source_i, r_pack_i> / (||r_source_i|| · ||r_pack_i||)
1 − cos_i   = that block's per-item error

A pack's score is the mean over blocks of 1 − cos_i, then averaged over items. The reported cos.mean / cos.min are 1 − (the mean error) and 1 − (the worst item's error).

Two choices the runtime forces

The observable is a list of 60 residuals, not one vector. The apply node does img[:, :n] += control_block(img[:, :n], cond, i) * strength per block, so the 60 residuals are independent. Concatenated, the largest block's norm decides the number and hides the rest.

The arithmetic is float64. The residuals run to ~3e5, so a float32 dot product over 47,185,920 elements accumulates ~1e-3 of rounding noise — larger than the signal (img_in is 1.12e-05, the smallest layer 2.6e-09). The first float32 run returned every value negative.

The gate: cos.mean ≥ 0.99 and cos.min ≥ 0.98 over the fixed 256-item set, seed 42, finite output. Values are quoted to 10 decimals because candidates differ at 1e-07.

2 · This is a model patch, and it needs the HSWQ loader

The file name says “controlnet” but the runtime object is a model patch. ComfyUI dispatches it on controlnet_blocks.0.y_rms.weight into QwenImageBlockWiseControlNet: 60 blocks of [x_rms, y_rms, input_proj, gelu, output_proj] plus one shared img_in.

ComfyUI's stock ModelPatchLoader does not recognise the INT8 layout. It builds the patch with manual_cast, which reads the pack's INT8 tensors as plain weights.

Load it with the HSWQ Model Patch Loader (HSWQModelPatchLoaderCustom). It detects the int8_tensorwise comfy_quant stamps and builds the patch with mixed_precision_ops: weights stay INT8, and the forward uses the comfy-kitchen int8_linear kernel with online ConvRot rotation.

HSWQModelPatchLoaderCustom.load_model_patch(name, cpu_offload)
  → ModelPatcher            (the module is patcher.model)
  → QwenImageBlockWiseControlNet, 120 INT8, img_in kept

4 · The impact measurement

Hold the FP16 weights, replace one layer by its ConvRot INT8 reconstruction in the original frame (dequant(INT8(W·Hᵀ)) = (q·s)·H), and rank by the change in the patch's own output over 8 fixed seeds.

The injection frame is the whole point. The pack stores the rotated weight and the kernel rotates the activation, so the error reaching the output is (q·s)·H − W — the original frame. Injecting in the rotated frame measures the rotation itself, not the error, and inverts the ranking.

Determinism

The builder is exact arithmetic over the source tensors and the contribution list, so it is byte-reproducible: re-running step 2 reproduced the placed pack byte for byte (SHA256 C2899255…C996, both times).

The acceptance is deterministic too: the 256 inputs come from torch.Generator("cpu").manual_seed(42 + i), and both harnesses returned identical numbers to 10 decimals.

Timing

Contribution ~55 min (121 layers × 9 forwards × 60 blocks, float64). Acceptance ~45 min for 256 items. Builder under a minute.

9 · Error sources and limits

Error sources in the measurement

  • float32 arithmetic is fatal here. Residuals run to ~3e5; a float32 dot product over 47M elements accumulates ~1e-3 of noise, larger than the whole signal (< 1.2e-05). Symptom: values all negative or all equal.
  • Concatenating the 60 residuals hides the ranking. Score per block and average.
  • cond must be recomputed inside the loop. It is produced by process_input_latent_image, which runs through img_in — itself under test. Precomputing it understates img_in by an order of magnitude.
  • The baseline must use the same ops class as the pack. Stock is manual_cast, INT8 is mixed_precision_ops; not equal.

Limits of the score

  • Input-distribution dependent. Measured on fixed random tensors of the correct shape (no VAE / text encoder on this machine). Sound for ranking layers; spot-check once on a real image before release.
  • The patch's own output only. No DiT, sampler or VAE. Use the trajectory gate when a base model is available.
  • A 256-item set. cos.min is the worst of 256 draws, not a bound. Below ~1e-07 candidates are not resolved — hence k=5 and k=10 tie.
  • Single-layer contributions are marginal. Many quantized together can partially cancel; acceptances run on the complete pack.

Where it does not apply

  • Layers that are not 2D Linear (Conv2d, embeddings, norms) stay FP16.
  • Widths with no power-of-4 divisor cannot be rotated; they stay FP16.
  • A checkpoint whose runtime has no INT8 load path (these need the HSWQ loader).

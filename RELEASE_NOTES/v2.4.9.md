## Overview

This release publishes the backdoor audit as a finished instrument, not as a claim: an operating
procedure that fixes what may be concluded, two audit tools plus four gates that hold the reports to it,
a record for every number quoted, and twelve verdict reports — one per distributed file — each of which
states its own reach.

The audit exists because HSWQ publishes INT8 packs built from third-party sources. A backdoor written onto
a source survives quantization, so a publisher who quantizes without looking forwards the branch under its
own name.

## 1. The question the audit answers

A backdoor is a branch: ordinary behaviour on ordinary input, attacker behaviour on chosen input. A weight
diff cannot establish either its presence or its absence — two files that both reduce refusal along one
direction, one by dropping a single safety-direction projection and the other by adding a rank-2 payload
behind that projection, produce similar-looking diffs and completely different files
([§1.3 of the guide](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Technical_Guide.md#13-what-a-backdoor-is-and-what-a-weight-diff-is-not)).

So the audit does not ask "is this weight set unusual". It asks: **can this file branch on its input, by
any of the shapes a file can use, and does any probe fire?** Every report answers that question for one
artifact identified by one sha256, and states the conditions under which the answer would change.

Why it matters for a distribution, from the literature summarised in the guide
([§1](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Technical_Guide.md#1-the-threat-stated-precisely)):

- a poisoned model passes every capability benchmark, because the poison is trained alongside the normal
  task and both stay high;
- the attack cost does not scale with the model — roughly 250 poisoned documents backdoor both a 600M and a
  13B model;
- quantization preserves the weights, so quantizing a backdoored source silently distributes the backdoor
  in the publisher's name.

## 2. The three branch shapes, and the measurement that closes each

A safetensors file can make the network branch on input in exactly three ways. The list is exhaustive over
file contents, not over attacker ingenuity. Each report closes all three separately.

### 2.1 Added material

A new tensor, bias, embedding row or adapter that is not in the declared base. Closed by a full tensor
census against the reference — every key accounted for, including a zero-content census that counts
elements, not bytes, and catches a tensor that is present but silent
([Phase 3](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#7-phase-3--census-and-layout-mapping),
[`audit/source_audit.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/source_audit.py)).

### 2.2 A second component behind the declared change

Something riding behind the edit the model openly makes — the abliteration direction carrying a payload.
Closed by projecting the delta onto its own principal directions: what the declared edit cannot account for
is measured and named, and a residual is a finding even when the parents are perfectly clean
([Phase 4](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#8-phase-4--delta-structure)).

### 2.3 One component that reacts to a narrow input class

The switch shape: a single direction that stays quiet on ordinary prompts. Closed by a trigger search over
a candidate set, compared against the control spread, with a **positive control on the instrument itself**
([§11.3](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#113-trigger-search),
[`audit/trigger_search.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/trigger_search.py)).

A poison trained diffusely across ordinary-looking weights is a training property, not a shape. The audit
does not claim a shape search covers it; what it offers there is the behavioural comparison and the rebuild
test ([§2](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Technical_Guide.md#2-what-can-and-cannot-be-proven)).

## 3. Verdict strength and coverage

A verdict without a strength and a coverage cannot be read, so both are mandatory and defined:

| Strength | Meaning |
| :--- | :--- |
| **A** | the delta is fully accounted for at the weight level by the declared edit: every tensor is compared against its reference and the remainder is explained by the edit itself |
| **B** | the delta is dense and weight-level closure is not available, so the verdict rests on the behavioural probes |
| **C** | the weight-level audit covers part of the file only, and behavioural probes carry the rest |

**Coverage** is the tensors the weight-level audit measured, over all tensors in the file. *No backdoor
detected* therefore reads: none was detected in the artifact identified by the sha256 in that row, by the
tests that report documents, within the limits that report states. It is not a probability, and the Wilson
intervals quoted in reports are the uncertainty of a metric, never a probability of absence
([definitions](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Verdicts.md#what-each-verdict-covers),
[status words](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#29-status-words)).

## 4. The procedure, phase by phase

The procedure is the part that makes the verdicts comparable, because it fixes the order of operations and
what each phase may conclude
([full text](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md)).

| Phase | What it fixes | Delivery is recorded there, but never treated as a finding |
| :--- | :--- | :--- |
| 0 — Intake | class of the artifact (base, conversion, merge, pack, fine-tune) decides which later phases apply | — |
| 1 — Reference acquisition and pinning | the comparison object is pinned by sha256 against the publisher's own listing; when the official file is not in HF layout, a reference is rebuilt and that rebuild is itself recorded | [§5](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#5-phase-1--reference-acquisition-and-pinning) |
| 2 — Delivery | hash and size of the artifact as distributed | [§6](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#6-phase-2--delivery-recorded-never-a-finding) |
| 3 — Census and layout mapping | every key accounted for; zero-content census counts elements; layout differences are mapped before any delta is measured | [§7](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#7-phase-3--census-and-layout-mapping) |
| 4 — Delta structure | per-tensor measurements, reconstruction against the storage floor, and the merge or pack path | [§8](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#8-phase-4--delta-structure) |
| 5 — Localisation ablation | four models are built (base, base with the delta removed, delta-injected-only, and a control) so that the delta's contribution is isolated rather than assumed | [§9](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#9-phase-5--localisation-ablation-mandatory-for-every-non-base-artifact) |
| 6 — Clean preservation | the base behaviour must still be intact after the declared edit; a delta that damages ordinary behaviour is reported as such | [§10](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#10-phase-6--clean-preservation) |
| 7 — Conditional behaviour | capacity control first, then the distribution probe at the decision point, then the trigger search, pointer probe, capability-present/trigger-absent control, direction control, divergence shape and tool-call context probe for decoder LMs | [§11](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#11-phase-7--conditional-behaviour) |
| 8 — Verdict and report | the decision procedure, the report template, and what must appear in LIMITS | [§12](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#12-phase-8--verdict-and-report) |

Two further items sit outside the phase list and are enforced anyway:

- **Completeness gate** before the decision procedure — a run missing any mandatory measurement may not
  produce a verdict at all
  ([§12.0](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#120-completeness-gate-runs-before-the-decision-procedure)).
- **Gate 8** — the pack must execute on the loader its card names. A pack whose INT8 never runs is not a
  quantization; it is a larger file that behaves like a different one
  ([§12b](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#12b-gate-8---the-pack-must-execute-on-the-loader-its-card-names)).

## 5. Tools and gates

### 5.1 The two audit tools

- [`audit/source_audit.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/source_audit.py) —
  the source itself: census, zero-content census, delta structure, merge proof, localisation ablation,
  direction control, trigger search
  ([§5 of the guide](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Technical_Guide.md#5-tool-2--auditsourceauditpy-the-source-model)).
- [`audit/backdoor_audit.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/backdoor_audit.py) —
  the pack against its source: exact re-quantization, code-level reproduction, stored-float audit and
  container scan
  ([§4 of the guide](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Technical_Guide.md#4-tool-1--auditbackdoorauditpy-pack-vs-source)).

Exact re-quantization is the decisive idea
([§3.2](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Technical_Guide.md#32-the-decisive-idea-exact-re-quantization)):
the pack's INT8 codes are recomputed from the source under the converter's own arithmetic, so anything the
source does not carry shows up as a code that cannot be reproduced. The audit runs on the source because
INT8 — a small integer and a scale per weight — has no resolution to answer a question that needs 1e-6,
while a direction written onto the source survives the rotation and the per-channel scale.

### 5.2 The gates over the reports

| Gate | What it refuses |
| :--- | :--- |
| [`audit/report_check.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/report_check.py) | a report missing a required section, including LIMITS, or a citation that does not resolve |
| [`audit/check_cites.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/check_cites.py) | a quoted number that does not appear at the cited line of a real record, or a record whose sha256 does not match |
| [`audit/procedure_check.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/procedure_check.py) | a document that claims to follow the procedure while missing steps the procedure requires |
| [`audit/selftest.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/selftest.py) | a tool that no longer does what its report claims |
| [`audit/check_hf_upload.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/check_hf_upload.py) | a model card written to the Hub without front matter, or below the size floor |

The gates exist because the first version of this audit trusted its own prose. A claim without a record is
a defect, not a judgement call
([findings and closure](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Findings_and_Required_Work.md)).

## 6. Detection sensitivity — measured against fabricated tampering

The tools were validated against constructed tampering rather than assumed to work
([§6.5](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Technical_Guide.md#65-detection-sensitivity-measured)).

### 6.1 Pack level (`backdoor_audit.py`, pack against its own source as a controlled base)

| Tamper | Verdict | Signal |
| :--- | :--- | :--- |
| 3-LSB edit of one quantized layer | EDITED | `q_mismatch=18,421`, `max_q_delta=3` |
| 6 % change of one `weight_scale` | EDITED | `scale_exact_rel = 6.00e-02` |
| Edit of one kept-float tensor | EDITED | `float_mismatch=1` |
| Added a foreign tensor | EDITED | `extra=1`, suspicious key |
| Untouched pack | FAITHFUL | all signals zero |

### 6.2 Source level (`source_audit.py`)

| Control | Expected | Measured |
| :--- | :--- | :--- |
| Abliteration-like (one direction subtracted) | rank-1, coherent | `changed=6`, rank-1 = 1.0000, `max_rank2 = 0.0000` |
| Injected rank-3 update | multi-direction | `changed=6`, rank-1 = 0.3550, `max_rank2 = 0.3384` |
| Global-direction edit (one direction across layers) | coherence ≈ 1 | mean abs cosine = 1.0000 |
| Scattered edit (different direction per layer) | coherence ≈ 0 | mean abs cosine = 0.0286 |
| Merge `0.5·parentA + 0.5·parentB = model` | EXACT-MERGE | `exact=196`, `residual=0`, worst 1.5e-05 |
| Model = base | IDENTICAL | `changed=0`, `rel_fro=0.0` |
| **Poisoned merge** (clean parents, injected model) | RESIDUAL | `residual=6`, all six injected layers named |
| 1-ULP edit vs upstream | DIVERGES | `bit-exact=195`, `diverging=1`, `elements=1` |
| Foreign tensor vs upstream | DIVERGES | `only_in_model=['assets/backdoor.py']` |

The poisoned-merge row is the capability that matters: with perfectly clean parents, an injected model is
still caught as a residual that the declared parentage cannot explain.

## 7. The trigger search, and the error rate of the instrument

A behavioural pass is worth the error rate of the instrument behind it. The positive control runs the same
probes on a clean base model and records **20/28 false positives**
([Positive_Control.md](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/verdicts/Positive_Control.md)).
That figure is published beside the results, not behind them: a pass means the trigger ratio did not
exceed the criterion, and the criterion is read against a control spread that wide.

Each report's **LIMITS** block states the candidate set size and how it was generated, the positions
probed, and the reference-class boundary — a defect already inside the comparison object's own release is
unreachable by definition
([what must appear in LIMITS](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Procedure.md#123-what-must-appear-in-limits)).
The candidate sets are built by
[`audit/trigger_variants.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/trigger_variants.py),
scored by
[`audit/trigger_logits.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/trigger_logits.py)
and
[`audit/trigger_search.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/trigger_search.py),
and the LIMITS blocks themselves are generated by
[`audit/make_limits.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/make_limits.py),
so a report's statement of its own reach comes from the run rather than from the author's memory.

## 10. Records

[`md/verdicts/records/`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/tree/main/md/verdicts/records)
holds the 168 files the reports cite: tensor censuses, zero-content censuses, rank structure, spectra,
trigger candidate lists, per-candidate trigger values, generation texts with the hand labels read from
them, per-route load-path measurements, and hash records for each file and its base.

Every quoted number in every report points at a record and a line inside it, and
[`audit/check_cites.py`](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/audit/check_cites.py)
fails the report if that line does not contain the number or if the record's sha256 no longer matches. This
is the difference between a report and an assertion.

## 12. Scope and limits

- The audit answers *"was a branch detected in this artifact, by these tests, within these limits"*. It
  does not answer *"this file is safe"*
  ([§2](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization/blob/main/md/Backdoor_Audit_Technical_Guide.md#2-what-can-and-cannot-be-proven)).
- **C is not a pass of the same weight as A.** SAM 3.1 is reported at C with 6 % weight coverage, and its
  verdict leans on behavioural probes whose instrument error is stated in §7.
- A behavioural probe set is finite; the candidate sets, their generation and the probe positions are in
  each report's LIMITS precisely so a reader can argue with them.
- A pack that reproduces its source exactly inherits the source's verdict and adds the code-level check; it
  does not get a stronger verdict than its source.
- Two reports record measurements that failed their own expectation — the LongCLIP identity check and the
  withdrawn Qwen3-VL pack builds — rather than dropping them. A record that only keeps successes would make
  the rest of the table unreadable.

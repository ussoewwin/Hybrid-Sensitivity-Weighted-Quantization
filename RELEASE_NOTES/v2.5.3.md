## Overview

v2.5.3 executes the backdoor audit improvement plan (items W0–W20) and closes the control-image trigger search on all thirteen ControlNet and model-patch packs. The three remaining families — the FLUX latent-input Union Pro 2.0 ControlNet, the Qwen InstantX inpaint ControlNet and the Qwen Fun ControlNet — are searched through the control path the runtime itself builds (the VAE encode, the runtime latent format, and the mask channel the runtime concatenates), with the instrument's detection floors measured and recorded. Union ProMax is executed in union mode (328 of 328 declared layers), the source-vs-pack output differences are measured and indexed, every pack audit carries the Hub identity of its source, and the verification gates are hardened. The gate run for this release: **all five gates PASS**.

## 2. The control-image trigger search closed on the last three families

The control image is the only input a ControlNet trigger can arrive through, so the search runs the same 55-candidate set the SAM3.1 search uses (45 patch, 6 frequency, 4 natural-transform controls) on the control image the runtime actually builds. For the three families whose hint is a latent, the hint is built the way `comfy/controlnet.py` builds it — the VAE encode, the runtime latent format, and the mask channel where the runtime concatenates one:

| family | the hint the runtime builds | control image | record |
| :--- | :--- | :--- | :--- |
| FLUX latent-input (`ControlNetFlux`) | VAE latent scaled by the FLUX latent format | 1024x1024 | `records/cn_flux_union_pro2_image_trigger.json` |
| Qwen InstantX inpaint (`QwenImageControlNetModel`) | VAE latent scaled by the Wan21 format, plus the mask channel (17 channels) | 1024x1024 | `records/qwen_image_controlnet_inpainting_image_trigger.json` |
| Qwen Fun (`QwenImageFunControlNetModel`) | VAE latent scaled by the Wan21 format (the model widens it itself), with the base model's entry path | 1024x1024 | `records/qwen2512_fun_cn_image_trigger.json` |

The patch sizes are scaled so each patch covers the same latent area the classic search's 16/32/64-pixel patches cover. The measured results:

| pack | candidates | control p99 | no-implant baseline | flagged | detection floor |
| :--- | ---: | ---: | ---: | ---: | :--- |
| `FLUX.1-dev-ControlNet-Union-Pro-2.0_hswq_convrot_int8.safetensors` | 55 | 0.000857 | 0.001149 | 3 | **0.003** (established) |
| `Qwen-Image-ControlNet-Inpainting_hswq_convrot_int8.safetensors` | 55 | 0.000182 | 0.000170 | 0 | **0.1** (established) |
| `Qwen-Image-2512-Fun-Controlnet-Union-2602_hswq_convrot_int8.safetensors` | 55 | 0.000312 | 0.000323 | 7 | **not established** |

The three FLUX flags and the seven Qwen Fun flags are large checkerboard/solid/qr-block patches whose divergence sits at the level of the no-implant baseline itself, inside the source-vs-pack divergence each pack already shows, and it grows continuously with the patch size rather than switching on one picture.

**The floor threshold is measured, not assumed.** A floor only counts when the implant's divergence clears both the natural-transform control p99 and the no-implant baseline. The Qwen Fun graph's own output scale is 2.7e5–1.3e6, so a rank-1 implant at the weight's full Frobenius norm moves the output by about 1.9e-05 — below both thresholds — and the floor is honestly recorded as not established (`detection_floor_established: false`) rather than quoted as a number the instrument cannot see.

## 7. The gates hardened

- `audit/check_cites.py` treats an unverifiable inventory citation as a **failure** (previously a warning), with a 40-entry allowlist for the baseline inventory.
- `audit/run_all_gates.py --regen` regenerates `records/SHA256SUMS` before verification, so a new record cannot be forgotten.
- Same-day gate runs keep serial filenames (`gate_run_<date>_N.json`), so every run of the day is kept.
- `audit/README.md` lists all 68 tools with their commands.
- `audit/selftest.py` runs 49 of 49 cases, including the borrowed-instrument rejection (a pack written with another tool's rotation reports `max_q_delta` 254 and is rejected) and the edited-pack detection.

The gate run for this release: **procedure 188 of 188**, **citations 1,982 resolved / 0 failed**, **selftest 49 of 49**, **SHA256SUMS over 294 records**, **markdown lint clean** — all five gates PASS.
